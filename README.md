# Jesús Gala Coach – web estática

HTML + CSS sin dependencias. Para publicarla:

1. Ejecuta `sh descargar_assets.sh` (descarga imágenes y vídeos de la web antigua a `assets/`). Hazlo antes de dar de baja el hosting.
2. Sube todo a un repositorio de GitHub.
3. En *Settings → Pages*, elige la rama `main` y la carpeta `/ (root)`.

Los vídeos pesan: GitHub admite hasta 100 MB por archivo. Si pesan más, súbelos a YouTube y sustituye la etiqueta `<video>`.
